# Task 2 – Python Recap

## Objective

To understand Python Object-Oriented Programming (OOP), classes, objects, methods and modules.

## Concepts Learned

### 1. Class

A class is a blueprint used to create objects. I created a class named Book.

### 2. Object

An object is an instance of a class. I created three objects representing three different books.

### 3. Constructor

The `__init__()` method initializes an object's attributes when it is created.

### 4. Attributes

The Book class contains two attributes:

- title
- author

### 5. Method

The `describe()` method displays the title and author of a book.

### 6. Modules

A Python module is a file containing reusable Python code. I created `library.py` and imported its Book class into `main.py`.

## Files Created

- `library.py`: Contains the Book class, constructor and describe() method.
- `main.py`: Imports the Book class, creates three book objects and displays their information.

## Result

Successfully created and executed a Python program using classes, objects, constructors, methods and modules. All three book objects displayed their respective titles and authors correctly.
